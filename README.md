# Global Carbon Emissions Dashboard

Statische Website im Rahmen einer Fallstudie zum Thema CO₂-Emissionen.

## Funktionen

- Globale Navigation
- Lokale Navigation
- Responsive Darstellung
- CO₂-Datentabelle
- Filterung nach Land und Unternehmen
- Sortierung nach Land und Unternehmen
- Kontaktformular

## Hinweis

Die dargestellten CO₂-Daten und Unternehmen sind fiktiv und dienen ausschließlich
der Durchführung der Fallstudie.
